## Running it locally

The small program in `main.ts` simply copies `POST.json` to the output folder where the grader reads it. To try it yourself:

```
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

After it runs, `out/POST.json` will contain the post address shown above.
